# RM2026_LaserMount
RM2026雷达的激光座部分


## 装配要点

1. **半反半透镜**：45° 的大概初始角度尽可能精确，可减少后期的调节量
2. **消光处理**：内部贴黑色绒布，最大限度减少结构内反射红斑
3. **激光头对准**：12mm 激光头插入后，确保中心与透镜几何中心对齐
4. **固定方式**：所有螺纹孔使用 M2/M3 镶嵌螺母
5. **镜头连接**：本结构为海康 MVL-HV1050M 镜头设计，其他镜头需自行适配

## 已知问题与限制

| 问题 | 原因 | 缓解措施 |
|------|------|----------|
| 成像红斑 | 激光在结构内部多次反射 | 内部贴黑色绒布吸光；选用反射比较高的半透镜 |
| 光功率损失 50% | 半反半透镜分光特性 | 选用高灵敏度相机；激光功率选高（<1mW 安全范围） |
| 飞弹碰撞 | 有受击风险 | 建议加装防护罩 |

## 设计演进（简述）

- **V1**：仿枪械三点一线瞄准 → 失败（激光是直线，无弹道补偿）
- **V2**：精密调节底座（三颗螺丝调平行）→ 放弃（3D 打印精度不足，结构复杂）
- **V3**：光轴同轴反射（本方案）→ 采用（几何上彻底消除视差）

## 测试验证结果

- **距离无关性**：5m/20m/50m 测试，验证激光点始终与画面中心重合
